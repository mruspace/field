# Contributing to Mru Field

Thank you for your interest. Mru Field is a specification today; no code runs yet. Comments on the specification are welcome as pull requests or by email to contact@mru.space.

## Rules for changes

- State what exists. State plans as "planned".
- Every number has a source and a scope.
- Straight apostrophes, no em dashes, US spelling.
- Keep README, LICENSE and TRADEMARK current.
